Politique de confidentialité RGPD simplifiée

Nous ne collectons pas de données personnelles identifiables. Les données suivantes sont stockées localement sur votre appareil :

  • Historique de recherche dans IndexedDB (query, localisation, timestamp)
  • Données produit en cache (code-barres, informations produit)
  • Préférences utilisateur (paramètres voix, priorité comparateur)

Vous pouvez supprimer ces données à tout moment via le bouton ci-dessous. Aucune donnée n'est transmise à des tiers sans votre consentement.
